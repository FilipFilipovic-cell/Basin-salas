# Bašin salaš

Statična web stranica (HTML + CSS) za salaš: naslovna, filozofija, cenovnik i kontakt.

**Demo:** https://filipfilipovic-cell.github.io/Basin-salas/

## Fajlovi

- `index.html` – cela stranica
- `basin-salas-logo-transparent.png` – logo
- `salas.jpeg` – fotografija objekta
- `cenovnik.jpeg` – karta pića

Sve slike moraju biti u istom folderu kao `index.html`.
